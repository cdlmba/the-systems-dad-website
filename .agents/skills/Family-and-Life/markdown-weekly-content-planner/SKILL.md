# Weekly Content Architect: Systems Dad Edition

Use this skill to architect a week's worth of social media content that balances professional authority with personal Dad Life systems.

## The 6-Day Framework

| Day | LinkedIn (PM/AI/Leadership) | Twitter/X (Home/Family/Systems) |
|---|---|---|
| **Mon** | **Startup Strategy**: ROI of prep/systems (Post 1). | **School-Run Protocol**: Morning automation. |
| **Tue** | *Engagement Focus* (No post). | **Boundary Systems**: Home office rules. |
| **Wed** | **Decision Velocity**: Avoiding bottlenecks (Post 2). | **Logistics Engine**: Meal prep/grocery systems. |
| **Thu** | *Engagement + Analytics* (No post). | **Memory Audit**: Traditions and presence. |
| **Fri** | **The Friday Shutdown**: Closing loops (Post 3). | **Minimum Viable Weekend**: Outsourcing. |
| **Sat** | *OFF* | **Presence Mode**: No-phone Saturdays. |

## Content Standards (The Systems Dad Pulse)

### 1. The Platform Slant
- **LinkedIn**: Professional, high-leverage, technical (but relatable). Focus on being a world-class Program Manager using AI to buy back time.
- **Twitter/X**: Soulful, punchy, tactical. Focus on the Dad side—how the same systems used at work keep the dinner table peaceful.

### 2. Mobile-First Formatting
- **Verticality**: Double line breaks after every punchline.
- **One Thought Per Line**: Avoid paragraphs longer than 2 lines.
- **Scroll Optimized hook**: Catch interest in the first 200 characters.

### 3. Anti-AI Slop Pass
- No "Pivotal," "Landscape," "Harnessing," or "Delve."
- Use "helpful big brother" tone.
- Inject specific failure modes and Dad realities (toddler tantrums, late-night chores).

## Output Requirement
For each day, provide:
1. **LinkedIn Post**: Optimized for the professional feed.
2. **X Post (Long-form)**: Optimized for the scroll.
3. **Visual Suggestion**: Brief concept for an image or Reel.

Now, architect the upcoming week based on the user's focus.
