# Daily Planner Architect

## Use this skill when
- Starting your day or planning the night before
- You have a complex schedule balancing technical work and family commitments
- You want to ensure "Deep Work" sessions are protected

## Step-by-step instructions
1. **Identify the Big 3**: What 3 outcomes would make today a win? (Include 1 personal/dad goal)
2. **Time-Block**: Create blocks for:
   - Deep Work (90-120 min sessions)
   - Administrative/Shallow Work (emails, Slack, chores)
   - Family/Dad Time (undistracted)
3. **Systems Check**: Identify one small system or automation to improve today
4. **Shutdown Ritual**: Define the time and steps to close the day mentally

## Best practices
- Use H3 headers for each time block
- Use task lists (- [ ]) for specific actions
- Add a "Wins of Yesterday" section for momentum
- Maintain the "Systems Dad" voice: Encouraging and disciplined
