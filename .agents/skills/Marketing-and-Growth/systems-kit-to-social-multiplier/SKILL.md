# Kit Content Multiplier: Multi-Channel Presence Engine

Use this skill to transform one deep-dive essay or Tactical Tuesday newsletter into a multi-platform campaign. 

> [!IMPORTANT]
> **Operational Truth**: Don't waste "Presence" hours writing separate posts. Extract the **Levers** from your existing thinking.

## Repurposing Slants

Analyze the provided Kit newsletter markdown and generate the following "Buffer-Ready" blocks.

### 1. The LinkedIn Pass (The "Professional API")
- **Focus**: Program Management, AI Operationalizing, Leadership, ROI of Efficiency.
- **Hook**: Start with a high-stakes professional observation (e.g., "Burnout isn't a mindset failure; it's a structural one.").
- **Formatting**: One thought per line. Double line breaks. Vertical scroll-optimization.

### 2. The X Pass (The "Home API")
- **Focus**: Presence, Dad-life logistics, "Systems Dad" identity, The Friday Shutdown.
- **Hook**: Start with a punchy, low-level home friction point (e.g., "The 'Shoe Chaos' of a 7:00 AM weekday is a logic gap.").
- **Threading**: Break the core concept into 3 separate threads or 1 long thread (Buffer allows scheduling threads).

## Buffer Formatting Standards

- **Character Limits**: Under 280 for X. Under 3,000 for LinkedIn.
- **No Manual Placeholders**: If you mention an image, describe exactly what should go in the [IMAGE_PATH] so it can be dragged into Buffer.
- **Protocol**: Every post must end with a clear CTA to the **Systems Dad Audit** or the **Kit Newsletter**.

## Creative Process
1. **The Root Logic**: Identify the "Big Idea" or "Lever" in the Kit article.
2. **The Slant Swap**: Reframe that "Lever" for the workplace (LinkedIn) and the household (X).
3. **The Mobile-First Pass**: Edit for brevity and "Scroll-Stopping" hooks.
4. **The CTA Bridge**: Ensure the link is contextually relevant to the specific slant.

## Output Requirement

1. **LinkedIn Draft**: 1 Post (Buffer formatted).
2. **X Drafts**: 3 Posts/Threads (Buffer formatted).
3. **Visual Recommendations**: Image prompts for DALL-E or photography choice.

Repurpose the Thinking. Protect the Presence.
