## 🖋️ Prose Governance (The Orwell Protocol)

These govern prose: docs, PR text, messages. Never touch code or technical terms; swap in everyday words only where precision survives.

1. Never use a metaphor, simile or other figure of speech which you are used to seeing in print.
2. Never use a long word where a short one will do.
3. If it is possible to cut a word out, always cut it out.
4. Never use the passive where you can use the active.
5. Never use a foreign phrase, a scientific word or a jargon word if you can think of an everyday English equivalent.
6. Break any of these rules sooner than say anything outright barbarous.

Review every prose output against these rules before delivering.

## 🛡️ The Cross-Linking & Hard Wall Rules

To prevent brand cannibalization and keep conversion paths clear, strict cross-linking protocols are enforced at all times:

1.  **TSD → MR**: Soft CTAs in TSD blog posts, newsletter footer, and about page only: *"If you're in active crisis and need to reset your workday transition tonight, I built a specific tool for that: marginreset.com"*. Never link to TSD checkout links directly on X.
2.  **TSD → CLS**: CLS remains invisible from TSD, except for a quiet footnote mention on the TSD About page: *"Christopher also consults professionally for tech organizations at christopherlynnsystems.com"*. **Exception (The Bridge Protocol):** CLS/Work concepts (like Program Management or Board Governance) can be used as the *Hook/Story* in a TSD newsletter, provided the conclusion (The Move) bridges the lesson back to the home/family. No B2B products can be pitched.
3.  **MR → TSD**: Footer attribution: *"Built by Christopher Lynn — follow the full story at thesystemsdad.com"*. MR assumes trust already exists downstream.
4.  **MR → CLS**: Enterprise footer link: *"Enterprise consulting: christopherlynnsystems.com"*.
5.  **CLS → TSD**: A quiet footnote whisper in the CLS footer: *"Personal brand: @TheSystemsDad"*.
6.  **CLS → MR**: Never. CLS is strictly B2B and does not mention B2C crisis products. Enterprise VPs do not need to see the $97 kit.
7.  **Social Proof Routing**: Social proof must be categorically siloed when injected across brands. Work-output testimonials (e.g., reclaimed time, reduced meetings) from CLS can be used to sell professional MR consulting (e.g., the $2,500 reset), but NEVER to sell family-oriented products (the $97 kit). Conversely, podcast highlights focused on home/family connection (TSD) are used exclusively for MR top-of-funnel and family-kit conversion paths.
