# Markdown Changelog Generator

## Use this skill when
- Creating or updating a project's CHANGELOG.md
- Summarizing git commits or release notes into readable format
- Preparing for a new version release

## Instructions
1. Collect all changes (commits, tickets, agent outputs).
2. Categorize into: Added, Changed, Deprecated, Removed, Fixed, Security.
3. Follow [Keep a Changelog](https://keepachangelog.com/) format:
   - ## [Unreleased]
   - ## [x.y.z] - YYYY-MM-DD
4. Use clear, user-focused language (not just technical commit messages).
5. Include links to issues/PRs when possible.
6. Always maintain the existing style when updating.
