## 🚨 MANDATORY PRE-PRODUCTION GATE

**No content drafting begins until this gate is cleared. This is a hard stop, not a suggestion.**

Before writing a single sentence of copy, the agent MUST:

1. **Load `cmo-marketing-governance/SKILL.md`** and confirm:
   - The ONE person is named (Alex Rivera, Pastor David, or Sarah Chen — never "everyone").
   - The Mike Kim Matrix is active: Heart (PB3) + Voice (POP) + Ear (ONE) are all present in the content plan.
   - The content answers exactly ONE of the avatar's #1 questions. Not two. One.

2. **Load `voice-and-tone/SKILL.md`** and confirm:
   - The correct Mode is identified: **Mode A** (TSD / Coffee with a tired friend) or **Mode B** (CLS / Lead Architect).
   - The four-layer editing stack is queued for post-draft review: Coffee Test → AI Tell Protocol → Orwell Protocol → First Read Test.
   - At least one element from the Emotion Vocabulary register is identified as the post's emotional anchor.

3. **Run the Specificity Probe** on the raw input before writing begins:
   - Does the hook contain a time, a physical object or location, or a body response? (If not, the hook fails Gate 1.)
   - Is there a real personal experience anchoring this content — a real scene, a real decision, a real outcome?
   - Is there at least one clear, un-hedged opinion on the record?

> [!CAUTION]
> If any of these three checks cannot be confirmed, STOP. Do not draft. Ask Christopher for the missing raw material first. Content produced without this gate produces AI-flavored generic copy that gets buried in the feed.

### 🎙️ The Recording-First Input Protocol (Alternative Activation Path)

When full RTT bandwidth isn't available, a 60-minute raw voice memo can serve as the Content Multiplier's primary input. This is a lighter-weight activation path that yields standalone content without requiring a full RTT first.

**The Three-Step Process:**
1. **Record** — 60 minutes, voice memo. Anchor it to the five questions clients or readers ask most. No script. Raw talk.
2. **Fragment** — Transcribe and cut into 12–15 standalone ideas. Each idea = one potential post. One idea per post — never combine.
3. **Reformat** — Map each idea fragment to one of the Four Universal Format Aliases above, route to the correct pillar, and schedule two weeks out.

**When to activate this path:**
- Christopher doesn't have a specific RTT story ready but wants to maintain posting velocity
- The content desk needs to rebuild a depleted backlog
- A Saturday drafting session needs raw material not anchored to a recent lived moment

**Output from this path:** Up to 12–15 X post drafts (one per fragment) + 1 newsletter issue + 2 short-form video scripts. Does NOT automatically trigger the CLS Loop or Closing Window Loop unless a daughter/window-specific idea surfaces during fragmentation.

> [!NOTE]
> This path does not replace the RTT. The RTT remains the primary engine. The Recording-First path feeds the backlog *between* RTT cycles.

## 🖋️ Prose Governance (The Orwell Protocol)

These govern prose: docs, PR text, messages. Never touch code or technical terms; swap in everyday words only where precision survives.

1. Never use a metaphor, simile or other figure of speech which you are used to seeing in print.
2. Never use a long word where a short one will do.
3. If it is possible to cut a word out, always cut it out.
4. Never use the passive where you can use the active.
5. Never use a foreign phrase, a scientific word or a jargon word if you can think of an everyday English equivalent.
6. Break any of these rules sooner than say anything outright barbarous.

Review every prose output against these rules before delivering.
*   **The Pacing Governor**: Strictly enforce the 60/40 rule (60% story/observation, 40% fix). Do NOT mash all catchphrases into a single post.
*   **Teaching Architecture**: Rotate through the 3 architectures (Real Example / Contrasting Outcomes / Before-During-After) as defined in the core Voice & Tone skill.

### 2. Lexicon Enforcement
| Area | Use | Avoid |
| :--- | :--- | :--- |
| **Productivity** | Systems, Capacity, Margin, Leverage | Hustle, Grind, Life-hack |
| **Leadership** | Architect, Alignment, Capacity | Manager, Supervisor, Boss |
| **Workflow** | Cycle, Rhythm, Cadence | Optimization, Scaling, KPI |
| **Emotional Result** | Presence, Calm, Legacy, Window | Busy, Effective, Efficient |
| **Time Urgency** | Window, Years, Before she leaves, Shrinking | Running out, Too late, Regret |

### 3. Mobile-First Formatting
*   **One sentence per line**: For maximum white space.
*   **The 8-Word Hook**: Value promise must be in the first 8 words.
*   **Pattern Breaks**: Use bulleted lists effectively.
