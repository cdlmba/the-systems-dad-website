# X/Twitter Thread Generator (Markdown Edition)

## Use this skill when
- You want a complete, ready-to-copy X thread (or thread draft)
- Explaining a tool, hack, lesson, framework, or story in bite-sized, engaging format
- Need content for @TheSystemsDad audience: practical, relatable, systems-focused, dad-friendly tone
- Turning notes, ideas, agent outputs, or long-form content into viral X threads

## Do not use this skill when
- You need long-form blog posts or full articles (use markdown-authoring-assistant or docs-generator)
- Output should be plain text without thread structure

## Step-by-step instructions
1. **Understand the goal**: Identify core message, audience (busy dads/devs/builders), desired length (usually 5–12 tweets), and tone (friendly, practical, ⚙️ emoji-heavy, encouraging).
2. **Craft the hook (Tweet 1)**: Must stop the scroll. Use:
   - Numbers ("7 ways...", "How I saved 2 hours/day...")
   - Questions ("Tired of [pain]?")
   - Bold claims ("This changed everything...")
   - Promise clear value
   End with "🧵 Thread:" or "Here's how:" to signal more.
3. **Body tweets (2–N)**:
   - One main idea per tweet (max 250–270 chars for safety)
   - **Scroll Segmenting**: Use double line breaks between sentences. One thought per line.
   - Short sentences + white space for mobile scannability.
   - Use numbering (1/, 2/, etc.) or emojis (⚡, 🔧, 👨‍👩‍👧) for vertical list visual pulls.
   - Include storytelling, examples, quick wins, pitfalls.
   - Add engagement: questions ("What's your biggest [pain]?"), polls vibes, relatable dad moments.
   - Build momentum: tease next insight.

4. **Closing tweet**:
   - Summarize key takeaway.
   - Strong CTA: "What system are you building next? Reply below 👇", "RT if this saved you time", link to GitHub/Notion/your site.
   - Optional: hashtags (#SystemsDad #AI #Automation #Productivity) — 2–3 max.

5. **Format output**:
   - Use Markdown with clear separation.
   - Label each as **Tweet 1/**, **Tweet 2/**, etc.
   - Include character count per tweet (helps editing).
   - Add [Optional: Add image here] placeholders for visuals.

## Best practices (2026 Quality & Coherence)
- **Quality > Quantity**: One well-constructed, niche-coherent thread is worth more than five mediocre ones. Treat each post like it costs you something.
- **Niche Coherence**: Every thread must clearly point to your core authority (Systems/Dad-Life/AI).
- **The COH Framework**: Mandatory three beats for TSD content:
  1. **Chaos (40-50%)**: Name the specific, raw mess/trigger.
  2. **Operator (30%)**: Bridge to a professional system/skill transfer.
  3. **Human (20-30%)**: End with imperfection and "still figuring it out."
- **Hook Discipline**: Hook must deliver curiosity + value promise in <10 seconds.
- **Verticality is King**: Keep tweets punchy: 1 line + whitespace + 1 line.
- Avoid large blocks of text. If it's more than 2 lines, break it.
- Strategic emojis: 1–2 per tweet for visual anchors.
- Mix formats: lists, steps, stories, contrarian takes.
- Encourage replies/bookmarks/shares.
- End with open question or soft CTA to boost algo.
- Tone: Helpful big-brother vibe — encouraging, no hype, real results.
