# Markdown Authoring Assistant

## Use this skill when
- Drafting or improving any written content in Markdown format
- Need help with tone, structure, readability, or flow
- Creating user-facing content (blogs, landing pages, release notes)

## Step-by-step instructions
1. Understand the goal, audience, and key messages from the user.
2. Suggest or use a logical structure with clear hierarchy (H1 → H2 → H3).
3. Write in active voice, short paragraphs (max 4 lines), and scannable format.
4. Incorporate:
   - Strong headings
   - Bullet/numbered lists
   - Tables for data
   - Bold/italics/callouts for emphasis
   - Code blocks where relevant
5. Optimize readability: Aim for 8th-grade reading level unless technical.
6. End with alternative versions or options (e.g., more formal vs friendly tone).

## Best practices
- Always ask for clarification on audience and tone if not provided
- Use callout boxes (> [!NOTE], > [!TIP], > [!WARNING]) when helpful
- Maintain consistent voice throughout
- Suggest images or Mermaid diagrams when they would improve understanding
