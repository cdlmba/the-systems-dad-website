### **The "Leverage" Decision Logic**

For each high-drain task, decide on the **Reclaim Mode**:

*   **AUDIT**: Is this contributing to the "Critical Few" outcomes? If no, delete it.
*   **AUTOMATE**: Can a single AI prompt or a Zapier flow do this? If yes, build it.
*   **RECLAIM**: Who can own this process? If not you, delegate it using the **AI Delegate Assistant**.
