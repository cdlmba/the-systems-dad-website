# Prompt Snippet Manager (Markdown Vault)

## Use this skill when
- You've discovered a high-performing prompt and want to "save" it
- You need to refine a prompt structure for clarity and repeatability
- You're building a library of reusable "Systems Dad" or automation prompts

## Step-by-step instructions
1. **Identify the Intent**: What is the prompt's core goal? (e.g., "Refactoring Python code", "Drafting family itineraries")
2. **Standardize the Structure**: Use a consistent template:
   - Name/ID
   - Description
   - Prompt Body (with [placeholders] for variables)
   - Configuration (Model, Temperature, etc.)
   - Notes/Iteractions
3. **Categorize**: Use tags or directory-style organization in Markdown (e.g., #AI #Python #Dad-Life)
4. **Iterate**: Document what worked/didn't work in a "Changelog" section for the prompt

## Best practices
- Use fenced code blocks for the prompt itself
- Add a "Test Case" section for verification
- Keep the tone technical yet practical: Focus on reproducibility
- Mention "Systems Dad" context where relevant (e.g., "Prompt for scheduling kids' soccer games")
