# Markdown Knowledge Base Builder

## Use this skill when
- Turning messy notes or conversations into a structured wiki
- Creating interconnected knowledge systems for yourself or your team
- Maintaining evergreen content that agents can reference and update

## Do not use this skill when
- You need a one-off document (use docs-generator)
- The output needs non-Markdown formats

## Step-by-step instructions
1. **Gather and analyze** all source material.
2. **Define structure**: Create index.md, category folders, and page templates.
3. **Generate pages**: Each page gets frontmatter (title, tags, last-updated), overview, detailed sections, related links.
4. **Add links**: Use Markdown links or wiki-style [[Page Name]].
5. **Make searchable**: Add tags, categories, and a master index.
6. **Provide maintenance plan**: How to keep it up to date.

## Best practices
- Consistent file naming (kebab-case.md)
- Use Mermaid for relationship diagrams
- Include "Last updated" and "Sources"
- End with "How to contribute to this knowledge base" section
