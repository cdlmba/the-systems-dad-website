# Cognitive Load Linter: High-Authority Clarity Engine

Use this skill to refine your copy for maximum impact. Every word either buy back attention or burns it.

> [!IMPORTANT]
> **Principle 14**: The key is cognitive load reduction—prioritizing larger initiatives over granular details.

## The "Cognitive Slop" Audit (Forbidden Terms)

Replace these weak, passive, or overused "AI/Corporate" words with **Systems Dad Logic**.

| Forbidden (Slop) | Why it's Weak | The "Architecting Composure" Replacement |
| :--- | :--- | :--- |
| **Harness / Leverage (vague)** | Overused AI filler. | **Install / Use / Apply / Deploy** |
| **Elevate / Transform** | Vague promise of change. | **Scale / Increase / Reclaim / Fix** |
| **Unlock your potential** | Cliché. | **Exposing the Logic Gap / Reclaiming 20 Hours** |
| **Synergy / Collaboration** | Corporate buzzword. | **System Sync / Combined Leverage** |
| **Comprehensive solution** | Too many syllables. | **The Full System / The Protocol** |
| **Empower / Journey** | Soft, non-authoritative. | **Direct / Enable / Build for Presence** |
| **Follow-up / Nagging** | Database-level reactive voice. | **Governance / Audit / Verification** |
| **Checking in on status** | Status-chasing. | **Auditing the Official Fiction** |
| **Parenting / Household** | TSD-Specific Optimization. | **Domestic Portfolio / Home Infrastructure** |
| **Rules / Chores** | Soft / Oppressive. | **Protocols / Maintenance Rhythm** |

## Writing Standards (The Linter Pass)

### 1. The Active Hook
- **Passive**: "Our new course was created to help you with your systems."
- **Systems Dad**: "Install this 5-Day Reset to stop fighting your laundry and start being a father."

### 2. The Decision Friction Check
- Does this piece of copy ask for more than **one clear decision** (CTA)?
- If there are 3+ links, it's a "Logic Gap" in the funnel.

### 3. Presence Recall
- Every "Tech Move" must end with an "Attention Win" (e.g., "Automating this buys you 45 minutes of quiet presence before dinner").
### 4. The "No Quotes" Rule
- **Standard**: Do not use quotation marks for metaphors, proprietary frameworks, or brand concepts (e.g., use **Shadow Governance**, not *"Shadow Governance"*).
- **Reasoning**: Quotes signal "academic hesitation" or a lack of conviction. Dropping the quotes signals high authority and ownership of the concept.
- **Exception**: Use quotes ONLY for direct, verbatim speech from a specific individual.

### 5. The "No Hyphen" Rule (Brand Nouns)
- **Standard**: Avoid hyphenating multi-word brand terms in prominent headers, titles, or nouns (e.g., use **AI Enabled TPM**, not **AI-Enabled TPM**; use **High Stakes Governance**, not **High-Stakes Governance**).
- **Reasoning**: Clean nouns elevate the architectural aesthetic. Hyphens add visual noise that detracts from the "Architect" voice.

## 6. The Persona Switch (Mode Selection)
When reviewing, determine the brand context:

- **AI-TPM Mode**: Use high-stakes, **Strategic Program Management** authority. Focus on Portfolio Architecture. No "Big Brother" warmth.
- **TSD Mode**: Use "Helpful Big Brother" warmth. Inject TPM analogies (Governance, Bottlenecks, SPOF). Focus on "Winning at Home." Target tone: **Architect with a Pulse.**

## Creative Process
1. **Mode Detection**: Identify if the piece is for the professional brand (AI-TPM) or the family brand (TSD).
2. **The Slop Scan**: Rapidly identify and purge any of the "Forbidden Terms."
3. **The The Residue Audit**: Count the number of CTAs. If >1, justify or remove the others.
4. **The Logic Pass**: Ensure every claim is backed by an "Operational Truth" (Real math, real time, real systems).
5. **The Tone Calibration**: 
   - **AI-TPM**: Ensure it sounds like a Lead Architect.
   - **TSD**: Ensure it sounds like a wise, tech-savvy older brother.

## Output Requirement
1. **The Core Edit**: A rewrite in the "Architecting Composure" voice.
2. **The Architect's Ledger**: A "Before/After" comparison table:
   - **The Human Database**: (Old, reactive, wordy version)
   - **The Portfolio Architect**: (New, direct, authoritative version)
3. **The Authority Leak Report**: A list of "Slop" and "Database Language" identified.
4. **The Presence Yield**: A statement on the "Time-Buyback" this edit provides.
