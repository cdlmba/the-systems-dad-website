# Usability AI Web Design

## Overview
This skill equips AI-assisted workflows with core principles from Steve Krug's *Don't Make Me Think* and Don Norman's *The Design of Everyday Things*. It ensures generated websites, UIs, and code prioritize intuitiveness, minimize cognitive load, and deliver exceptional user experiences—especially for brands like MarginReset.com or family/systems-focused sites.

## When to Use
- Crafting or refining prompts for AI code/UI generators (Tailwind, HTML/CSS, React, etc.).
- Auditing existing pages or wireframes for usability issues.
- Generating user flows, navigation, CTAs, or full site sections.
- Critiquing designs or A/B testing ideas.
- Ensuring mobile-first, accessible, scannable designs for busy users (e.g., tech dads).

## Key Principles Integration
**From *Don't Make Me Think* (Krug):**
- **Don't Make Me Think**: Make every page self-evident. Users should know what the site is, where they are, and what to do instantly.
- **Scanning & Billboard Design**: Prioritize visual hierarchy, clear headings, short text (halve words twice), high contrast.
- **Mindless Choices**: Obvious navigation, strong information scent, conventions (logo top-left, etc.).
- **Home Page & Navigation**: Clear purpose, breadcrumbs, persistent nav.
- **Test Early/Often**: Simulate user tasks.

**From *The Design of Everyday Things* (Norman):**
- **Affordances & Signifiers**: Elements must look/feel actionable (buttons with hover, labels + icons).
- **Mapping & Conceptual Models**: Logical control-to-outcome relationships; consistent mental model.
- **Feedback & Discoverability**: Immediate responses to actions; make key functions visible.
- **Constraints**: Prevent errors (disabled states, required fields marked).
- **Gulfs of Execution/Evaluation**: Bridge intent-to-action and action-to-understanding.

## Prompting Templates for AI Tools
Use these as base prompts, customizing for the task:

1. **Homepage Generation**:
   "Following Krug and Norman principles, generate Tailwind/HTML for a [site purpose] homepage. Ensure self-evident design, scannable content, clear CTAs with strong affordances/signifiers, visual hierarchy, and instant purpose communication via tagline. Mobile-first, minimal words."

2. **Feature/UI Component**:
   "Design [component] with Norman's affordances (obvious interactions), Krug's scanning optimization (hierarchy, whitespace), immediate feedback, and error constraints. Provide code + rationale."

3. **Audit/Critique**:
   "Audit this [code/description] against Krug's laws (don't make think, billboard design) and Norman's principles (affordances, feedback, mapping). List issues with fixes prioritized by cognitive load impact."

4. **Full Site Flow**:
   "Create navigation and user flows for [site] ensuring predictable mapping, breadcrumbs, and progressive disclosure. Minimize thinking at every step."

## Best Practices in AI Workflows
- Always include principles explicitly in prompts.
- Generate variants → critique against principles → iterate.
- For your projects: Emphasize low-friction for family/Christian dads—clear value (margin, presence), faith-integrated elements without clutter.
- Test: Role-play users in AI ("Simulate scanning by a busy parent"), then validate with real tests.
- Accessibility: High contrast, semantic HTML, keyboard nav (aligns with usability).
- Output: Provide code + explanations tied to specific principles.
