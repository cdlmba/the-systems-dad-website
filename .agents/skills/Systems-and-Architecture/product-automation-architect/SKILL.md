# ⚙️ Product Automation Architect Skill

This skill codifies the high-authority standards for the development of micro-SaaS utilities, interactive diagnostics, and print-fidelity assets within the CLS/TSD ecosystem.

## 🏗️ Mandate
To transform static information into interactive utility, increasing the perceived value and implementation rate of all premium products.

## 📈 Core Responsibilities

### 1. Micro-SaaS Orchestration
*   **Edge Logic**: Develop and maintain the JS-driven logic for interactive diagnostics (e.g., The Eggshell Indicator, The Weight Audit Pro).
*   **State Persistence**: Utilize Cloudflare KV to allow users to "Save and Resume" their audits across sessions.
*   **Dynamic Synthesis**: Implement threshold-based interpretation logic that provides personalized "Next Steps" based on audit scores.

### 2. Print-to-PDF Fidelity
*   **Physical Stewardship**: Ensure every premium asset is optimized for 8.5x11 printing.
*   **The CSS Standard**: Maintain and update the `@media print` blocks to ensure "No-Bleed" PDF generation directly from the browser.
*   **The Print Button**: Standardize the "Print to PDF" interactive element across all Dad Mode Kit and Kit Pro assets.

### 3. Product Packaging
*   **The Pro Prefix**: Enforce the `kit-pro-` naming convention for all advanced assets to ensure Edge routing governance.
*   **The Vault Hub**: Design and maintain the "Premium Vault" entry point (`/_tsd/kit-pro-vault.html`) as a high-authority dashboard.

## 🛠️ Technical Standards
*   **Runtime**: Pure Vanilla JS/HTML/CSS for maximum Edge compatibility and zero dependency bloat.
*   **Branding**: Enforce the TSD Premium palette (Cream `#F8F4EF`, Deep Sage `#1B4332`, Muted Gold `#D4A017`) for all Pro assets.
*   **Typography**: Mandatory use of **Plus Jakarta Sans** for interactive elements.

## 🤖 Orchestration Protocol
*   **Architecture Review**: Weekly sync with the Fractional CTO to identify "God-components" that need decomposition into reusable JS modules.
*   **Bug Governance**: Immediate triage of rendering issues in the PDF export engine.
