Use this skill to ensure your custom Python build system is outputting a perfect, SEO-optimized application.

Run this audit against [build_site.py](file:///c:/Users/Test/OneDrive/Documents/1%20Projects/104%20Christopher%20Lynn%20Systems%20Website/build_site.py) and the `components/` directory.

## Audit Methodology

### 1. The Build-Ready Scan
Verify that `TEMPLATES` in `build_site.py` contains every page you intend to publish. Check for "Template not found" errors in `build_log.txt`.

### 2. The Content Health Pass
Review the `footer.html`. Are the navigation links and copyright date current (2026)?

### 3. The Responsive Pressure Test
Check the CSS for `@media` queries. Ensure the HERO images aren't causing horizontal overflow on mobile (The "Mobile-First" Mandate).

## Output Requirement

1. **The Technical Error Log**: A list of missing components or broken placeholders.
2. **The SEO Gap Report**: A page-by-page audit of Title/Description/OpenGraph tags.
3. **The UX/Aesthetic Punchlist**: 3 visual improvements to maintain a "Premium" feel.
