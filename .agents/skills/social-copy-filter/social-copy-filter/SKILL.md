## Checklist (summary)

1. Swap table — shorter, blunter words
2. Sentence length — avg 8–12 words; max 15 on social; uneven cadence
3. Structure — no bullet posts, triads, em-dash stitching, negative parallel stacks, keynote closers
4. Jargon smell — warehouse-at-4:45-PM test
5. Physical object — at least one touchable prop
6. POV lock — I or You, no whiplash
7. Contractions — no Victorian robot grammar
8. Read aloud — rewrite stumbles

Only output after all pass.
