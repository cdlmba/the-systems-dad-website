# Workflow: TSD Growth Sprint

This workflow is a repeatable protocol for the **TSD Growth Architect** to execute high-authority outreach and content multiplication.

## 🏁 Phase 0: The Trigger
This workflow should be triggered every **Tuesday** after the "Tactical Tuesday" Substack is published, or every time a new `.md` file enters the `_posts/` directory.

---

## 🏗️ Phase 1: Content Multiplication (Triage)
1.  **Ingest Content**: Read the source Markdown file (e.g., `_posts/new-post.md`).
2.  **Synthesize Hook**: Identify the "Root System" and the "Human Friction" in the text.
3.  **Draft Array**: Generate the following in `OrganizationChecklist_tmp/outreach_desk.md`:
    *   **LinkedIn 1 (The Hook)**: Announcement version.
    *   **LinkedIn 2 (The Story)**: Vulnerable operator version.
    *   **X (The Logic)**: 3-5 post thread version.

---

## 🔍 Phase 2: Partnership Search (The Ladder)
1.  **Define Target**: Decide if this sprint targets **Podcast Hosts** or **Substack Partners**.
2.  **Research (Web Search)**:
    *   Find 3 guest opportunities where a "Systems Thinking for Dads" slant would be valuable.
    *   Identify the host's recent topics to customize the hook.
3.  **Draft Outreach**: Stage the customized "Bridge Outreach" for each target in the **Outreach Desk**.

---

## 📊 Phase 3: Reporting & Approval
1.  **Desk Sync**: Update `OrganizationChecklist_tmp/outreach_desk.md` with all new drafts.
2.  **Strategic Log**: Add a brief summary of the targets found to `MARKETING_LOG.md`.
3.  **Handshake**: Wait for CEO final approval in the desk.

---

## 🛠️ Outreach Signature (Protocol)
All generated outreach must end with this high-authority footer:
> *"I help leaders Lead at Work and Win at Home through Domestic Systems Architecture. Let me know if you’d like to explore a guest-spot audit for your audience."*
